# research-poster

A Claude Code skill that turns a PDF abstract into an editable scientific conference poster.

![Example poster generated by the skill: a fictional "Telehealth Adoption in Rural Primary Care" clinic-director survey, with native doughnut and bar charts, big-number stat tiles, and labeled sample sizes.](docs/example-poster.png)

*A fictional example, built by the script in `skills/research-poster/references/examples/`.*

## What you get

- A PowerPoint file, a PDF and a preview image
- Charts you can edit in PowerPoint
- Every chart labelled with its n/N
- Citations checked against PubMed and DOIs
- An optional match to an existing poster's style
- Checks for small text, overlaps and clipping
- Guided or hands-off runs

## Install

In Claude Code:

```text
/plugin marketplace add adamjali/research-poster-skill
/plugin install research-poster@research-poster
```

Or copy the skill in:

```bash
cp -r skills/research-poster ~/.claude/skills/
```

## What it needs

- Python 3, with `pip install -r requirements.txt`
- LibreOffice, or a Mac with Microsoft PowerPoint, to render the poster

## Use

Run `/research-poster`, or ask: *"make a poster from this abstract."* Attach the abstract PDF. A reference poster (`.pptx`) and logos are optional.

## Try the example

```bash
cd skills/research-poster/references/examples
python build_poster_example.py
bash ../../scripts/render.sh example_poster.pptx example_poster.pdf example_poster.png 1.7
```

## If it breaks

- **PowerPoint is open:** the PowerPoint renderer won't run. Save and quit PowerPoint first.
- **macOS asks for permission:** on the first run, let your terminal control PowerPoint.
- **Another skill takes over:** K-Dense's `pptx-posters` answers the same requests, and its `scientific-writing` bans bullets. Leave both out.

## Works well with (optional)

- Anthropic's `document-skills`, for editing an existing poster
- `frontend-design`, for colours and layout
- K-Dense's [`citation-management` and `scientific-visualization`](https://github.com/K-Dense-AI/scientific-agent-skills), copied into `~/.claude/skills/`

```text
/plugin marketplace add anthropics/skills
/plugin install document-skills@anthropic-agent-skills
/plugin install frontend-design@claude-plugins-official
```
